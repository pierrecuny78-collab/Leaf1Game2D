# Game assets

Place game-owned visual resources here. Suggested subfolders:

- sprites/characters
- sprites/creatures
- sprites/environment
- tilesets
- backgrounds
- ui

Default pixel-art canvas: 64x64. Other dimensions and conventional 2D artwork are supported.

For each imported asset, retain its source and license information in a nearby LICENSES.md or metadata file. Pinterest images are references only unless the creator's license explicitly permits reuse.
